# 짧은 실거래 기능시험

Live Trader의 `관리 → 주문 연결 시험` 화면에서 5·6·7시간 중 하나를 선택해 직접 시작한다. 이 화면은 전략 신호가 실제 주문·체결·종료로 이어지는지 확인하는 기능시험이다. 수익성이나 STANDARD 30일 Paper 검증의 통과 결과로 사용하지 않는다.

## 지원 범위

- Binance 현물, Binance USD-M 선물, Upbit 원화 현물, 한국투자증권 국내 현금주식.
- 5분봉·1시간봉·일봉의 전략 인스턴스와 포트폴리오 인스턴스. 여러 대상을 함께 선택할 수 있다.
- 거래소별 최대 100,000원, 이번 시험 시작 시점의 계좌 평가금액을 기준으로 수수료를 포함한 손실 중지선 50,000원. Binance 현물과 선물은 같은 100,000원 한도를 나눠 사용한다. 이 손실 기준은 여러 실행을 합산한 달력일 누적 손실 한도가 아니다.
- 실제 사용 가능 잔고가 적으면 그 잔고가 상한이다. 시작 후 추가 입금으로 시험의 상한을 늘리지 않는다.
- 전략의 원래 포지션 비율을 배정된 자금에 곱한다. 5% 원본은 5%로 유지한다. 새 `소액 배정금 100% 기능시험` 후보는 각 인스턴스에 배정된 소액 자금을 사용하는 별도 원본이며, 같은 거래소 총 100,000원 상한을 공유한다.
- Binance 선물은 실제 계좌가 1배·격리 증거금 조건을 만족해야 한다. 프로그램이 거래소의 레버리지나 증거금 설정을 바꾸지 않는다.

## 직접 시작하는 순서

1. 최신 `release/LiveTrader.exe`를 실행하고 거래소의 API 설정을 확인한다.
2. 앱의 기존 안전 확인 화면에서 실전 주문 라우트 활성화, 운용자 확인, Dry Run 해제, 신규 진입 허용을 직접 확인한다. 이 설정만으로 짧은 시험을 자동 시작하지 않는다.
3. `주문 연결 시험`에서 거래소·시간봉·인스턴스 또는 포트폴리오를 선택한다. 여러 시간봉이나 여러 전략을 선택하면 같은 자본을 나눠 사용하므로 최소 주문 금액 검사를 확인한다.
   오늘 사용할 새 후보는 이름에 `소액 배정금 100% 기능시험`이 표시된다. Binance 현물·Upbit은 BTC, Binance 선물은 SOL 후보가 준비되어 있다. BTC 선물은 현재 최소 수량만으로 예산을 넘을 수 있어 준비 검사에서 차단될 수 있다.
4. `무주문 준비 검사`를 누른다. 현재 잔고·계좌의 기존 주문 및 포지션·주문 수량 단위·수수료·환율·시세·실제 앱 소유권을 확인한다. 실패 사유를 해결한 뒤 다시 준비한다. 이 단계는 주문을 보내지 않는다.
5. 준비된 범위를 확인하고 `실제 주문 시험 시작`을 입력한 다음 시작 버튼을 직접 누른다. 시작 시 준비 결과와 현재 계좌를 다시 대조한다.
   준비 결과의 유효기간이 지나거나 선택·시험 시간을 바꾸면 무주문 준비 검사를 다시 진행한다. 화면을 여는 동작이나 후보 필터는 시험을 자동으로 시작하지 않는다.
6. 실행 중에는 앱과 PC를 유지한다. 정상 중지 버튼이나 지정한 종료 시간에 신규 진입을 막고, 이 시험이 소유한 미체결과 포지션을 확인해 정리한다. 전체 긴급 정지는 기존 긴급 정지 기능을 유지한다.

## 상태를 읽는 법

준비 가능, 실행 중, 주문 접수, 실제 체결, 포지션 없음, 작업 종료는 각각 다른 상태다. 시간봉에 전략 신호가 생기지 않았다면 주문이 없는 상태가 정상일 수 있다. 특히 일봉은 5~7시간 동안 새 봉이나 왕복 신호가 생긴다는 보장이 없다.

1시간봉은 완성된 봉으로 전략을 평가한다. Upbit은 시작 당시 진행 중인 일부 봉을 이력 보강에만 사용하고 연결 후 온전히 관측한 봉부터 평가하므로, 시작 시각에 따라 첫 평가까지 1~2시간이 걸릴 수 있다. 평가 횟수, 주문 시도 횟수, 실제 체결 관측 횟수를 각각 확인한다. 평가가 있어도 전략 조건이 충족되지 않으면 주문은 없을 수 있다.

작업 스레드를 만들기 전에 데이터 연결이나 이력 준비가 실패했다면 피드 종료와 계좌의 정리 상태를 확인한 뒤 시작 전 종료로 표시한다. 작업 스레드의 시작 여부나 실제 주문 결과가 미확정인 경우에는 정상 종료로 바꾸거나 같은 실행을 자동 재시도하지 않는다.

주문 전송 후 응답이 유실되면 결과 미확정으로 남긴다. 같은 주문을 자동으로 다시 보내거나 새 시험으로 덮어쓰지 않는다. 실제 거래소의 주문과 체결을 대조해야 한다. 앱을 재시작해도 기존 실거래 세션을 자동 복원하거나 재시작하지 않는다.

## 한국투자증권

국내 주식은 다음 정규장에 직접 확인한다. 선택한 시험 시간과 종료 정리 여유가 실제 장 시간 안에 들어와야 한다. 계좌·종목에 맞는 실제 수수료와 세금 확인 자료가 필요하며, 잠정 요율을 실제 확인으로 간주하지 않는다. 기존 장마감 수집 및 30일 Paper 예약은 중지된 상태다.

## 기존 자산과 준비 결과

Binance·Upbit 현물의 기존 코인은 준비 시 보유 수량을 고정하여 보존한다. 매수 자금은 사용 가능한 USDT·KRW이며, 기존 코인을 자동 매도하거나 환전하여 자금을 만들지 않는다. 정상 종료는 이 시험의 실제 체결로 생긴 수량만 정리한다. 준비 이후 기존 코인의 수량이 달라지면 다시 준비해야 하며, 실행 중 외부 거래나 입출금으로 수량이 맞지 않으면 신규 진입을 차단한다.

기존 코인의 시세 변화는 시험 손실 계산에서 제외한다. 시험 중에는 다른 프로그램이나 거래소 앱으로 같은 계좌에서 거래·입출금을 하지 않는다. 특히 추가 현금 입금은 계좌 평가금액 기준 손실 관측의 의미를 바꿀 수 있다.

준비 화면의 거래소별 잔고·최소 주문 검사 결과와 최종 시작 가능 여부는 구분한다. 저장된 ‘실전 주문 라우트’가 허용이어도 현재 앱의 권한이 잠겨 있을 수 있다. 앱 재시작 후에는 정상 확인 화면에서 다시 확인하며, 운용자 확인·Dry Run·신규 진입 차단도 시작 직전에 검사한다. 준비 검사 통과는 주문 체결이나 전략 수익을 보장하지 않는다.

후보 목록은 처음 열 때와 목록 갱신 때 별도로 읽고, 현재 실행 상태는 가벼운 조회로 계속 갱신한다. 표시용 목록을 보관해도 준비 시 원본 검증과 시작 시 계약의 원문 SHA 검증, 실제 계좌·시계 검사는 매번 수행한다.
