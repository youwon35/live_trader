# KIS 계좌 조회 범위와 환전·정산 준비

계좌를 읽을 때 선택한 한 종목의 정보와 별도로 국내·미국의 보유 종목 및 일반 미체결 주문을 기록한다. 이 결과는 조회 범위의 기록이며 계좌 전체 대조 완료나 실거래 권한이 아니다.

## 명시적으로 계좌 조회를 누를 때

- 국내 기본 잔고, 국내 정정·취소 가능 주문, 미국 전체 USD 잔고, 미국 일반 미체결 주문의 네 범위를 조회한다.
- 미국 실전 `NASD` 잔고 요청은 미국 시장 전체를 뜻한다. 종목 선택과 관계없이 고정된 범위를 요청한다.
- 각 범위는 최대 두 페이지까지 연속 조회한다. 연속 조회가 남거나 종료 헤더가 불명확하면 부분 조회 또는 미확인으로 표시한다.
- 조회 중 계좌·상품·통합증거금·수수료 설정이 바뀌면 결과를 폐기한다. 원본 전략과 포트폴리오도 다시 확인한다.
- 공개 화면에는 범위, 페이지 수, 행 수, 식별 가능한 행 수와 수집 시각만 표시한다. 계좌번호·잔고 금액·주문번호·원본 응답은 전달하지 않는다.
- 기존 15초 유효시간을 유지한다. 오래된 결과는 조회 기록으로만 남기고 재조회를 안내한다.

예약 주문, 정정·취소 불가 또는 조건 주문, 국내의 다른 시간대·거래소 잔고 범위, 미국 외 국가, 여러 요청을 묶은 원자적 잔고 시점은 이 네 조회로 증명되지 않는다. 빈 응답을 계좌 전체의 무보유·무주문 또는 0원으로 해석하지 않는다.

## 과거 수수료·환전·정산 확인

내부 읽기 전용 준비 함수는 호출자가 지정한 기간의 기존 해외 거래 내역을 읽는다. 한 번에 최대 90일(양 끝 날짜 포함), 두 페이지로 제한한다. 이 제한은 이 도구의 조회 예산이며 증권사의 전체 보관 기간을 뜻하지 않는다. 자동 실행이나 앱 시작 시 조회는 없다.

체결 수량, 외화 거래·정산 금액, 국내·해외 수수료, 원화 환산 금액, 등록 환율 필드가 보고되었는지를 구분한다. 출력에는 값 대신 존재 여부와 상태별 건수만 포함한다.

보고된 등록 환율은 자동환전의 실제 실행 내역을 뜻하지 않는다. 정산 날짜만으로 원화 출금·USD 입출금의 최종 반영을 확정하지 않는다. 거래 이력이 없거나 응답이 비어 있어도 계좌 적용 수수료율·환전 우대·잔고가 0이라고 추정하지 않는다.

## 계속 남는 실거래 조건

공통 원화 예약 기능은 국내·해외 주문이 같은 한도를 중복 예약하지 못하도록 유지한다. 실제 공통 현금 기준, 계좌 전체 의무, 외부 입출금과 환전·정산 최종 반영을 확인한 생산자 근거가 없으면 최초 기준 원장을 만들거나 예약을 자동 해제하지 않는다.

임시 수수료는 기존 경고 상태를 유지한다. 실제 계좌 적용 매수·매도 요율, 최소수수료, 우대 기간 및 자동환전 조건이 확인될 때까지 실제 비용 검증에 사용하지 않는다. 이 조회가 성공해도 Source, Backtester, Paper 자격, 주문 권한 또는 실거래 시작 제한은 바뀌지 않는다.
