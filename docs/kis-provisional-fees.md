# 확인 대기 중인 수수료로 준비하기

한국투자증권의 본인 적용 요율 답변을 기다리는 동안 공식 기본표로 수수료를 예상할 수 있다. 이 설정은 임시 계산용이며 실제 계좌 수수료 확인이나 실거래 시작을 대신하지 않는다. 기존 Source·Backtester·Paper의 수수료 가정도 변경하지 않는다.

## 기본값과 수정 위치

Live Trader **브로커 실계좌 연결 → 주식/ETF**에서 다음 값을 확인하고 수정한다. 단위는 **%**이며 `0.25`는 `0.25%`를 뜻한다. 값이 들어 있거나 저장됐어도 주황색 **임시값 · 확인 필요** 표시를 유지한다. 색상과 텍스트를 함께 사용한다.

| 설정 | 임시 기본 수수료 | 설정 키 |
| --- | ---: | --- |
| 국내 주식 KRX | 0.0140527% | `KIS_ESTIMATED_KRX_STOCK_FEE_PERCENT` |
| 국내 ETF KRX | 0.0146527% | `KIS_ESTIMATED_KRX_ETF_FEE_PERCENT` |
| 국내 주식 NXT | 0.0130527% | `KIS_ESTIMATED_NXT_STOCK_FEE_PERCENT` |
| 미국 주식·ETF | 0.25% | `KIS_ESTIMATED_US_FEE_PERCENT` |

뱅키스 기본 온라인 공개표를 참고한 값이다. 개인 우대·이벤트의 확정 요율이 아니며, NXT 설정의 존재가 NXT 주문 연결이나 거래 권한을 뜻하지 않는다. 기본값은 저장 파일이 없어도 표시된다. 명시적으로 입력한 `0`도 검증되지 않은 임시 0%일 뿐, 최소비용·세금·환전 비용까지 무료라는 뜻은 아니다. 비어 있는 값은 공개 기본값으로 돌아간다. 잘못된 요율은 설정·비밀키를 저장하기 전에 거부한다.

## 읽기 전용 계산

준비 화면에서 KIS 원본의 종목과 거래 수량·기준가격을 입력하면 계좌조회 없이 **입력 거래금액 × 임시 수수료율 ÷ 100**을 계산한다. 매수·매도 중 한 번의 거래에 대한 수수료 추정이며 왕복 총비용은 아니다.

Source가 주식·ETF를 구분하지 않는 경우 두 가지 대안으로 표시하고 종목명으로 추정하지 않는다. 국내 KRX는 원화, 미국은 달러 단위로 계산한다. 달러 수수료를 원화로 자동 환산하거나 원화 주문가능액을 달러 현금으로 바꾸지 않는다. 거래금액을 입력하지 않으면 수수료 금액도 미입력으로 남긴다.

계산은 정확한 십진수 곱셈이며 원·센트 절사 또는 반올림 규칙을 확정하지 않는다. 최소수수료, 매수·매도 세금과 유관기관 비용, 실제 자동환전 환율·스프레드, 정산 조정은 `미확인`이다. 이 항목을 0으로 간주한 총비용·최종 주문수량은 제공하지 않는다.

설정 변경 중 계산한 결과는 폐기하며 다시 계산한다. 새로운 임시 설정의 해시는 준비 보고서에 들어가지만 금융 검증 증명이 아니다. 계좌 실제 수수료 필드와 Source 비용을 덮어쓰지 않으며 통합증거금의 최종 국내·미국 주문 차단은 유지한다.

## 답변을 받으면 이어갈 순서

1. 본인 계좌의 KIS Developers REST API 매수·매도 적용 요율, 최소수수료, 우대 종료일과 자동환전 우대·적용 시점을 확인한다. 설정값 수정만으로 확인 완료 표시를 발급하지 않는다.
2. 같은 계좌의 국내·해외 전체 현금·미체결·보유 및 외부 변동 범위를 대조하고, 기존 로컬 공통 예약과 연결한다. 한 종목 또는 한 페이지의 조회로 전체 대조가 끝났다고 판단하지 않는다.
3. 실제 비용·자동환전·확정 결제 근거를 연결한다. 달러 잔고가 없는 통합증거금 계좌를 자금 부족이나 잔고 0으로 단정하지 않는다. 확정 근거 전에는 예약금을 자동 해제하지 않는다.
4. 현재 Source·Instance·Portfolio·정책과 정상 Paper/native 근거가 일치하는지 재검증한다. 과거 통과 이력만으로 현재 실행 자격을 대신하지 않는다.
5. 모든 조건을 통과한 뒤 사용자가 직접 실거래를 시작한다. 준비 화면이나 임시 요율 저장이 주문·원금 초기화·권한 활성화를 수행하지 않는다.

`paper`·`kis` 자동화는 사용자의 중단 요청에 따라 PAUSED 상태를 유지한다. 이 변경으로 예약 실행을 재개하지 않는다. 확인용 신규 매매·입금·환전도 필요 없다.
