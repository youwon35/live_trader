# Backtester 전략을 Live에 직접 연결하기

Paper Trader는 선택적으로 사용하는 모의 투자 시뮬레이터입니다. Live에 연결하기 위해 Paper 수익률, 30일 실행 또는 승급 기록을 만들 필요가 없습니다. Backtester의 연구 결과와 실제 주문을 허용하는 실행 점검은 서로 다른 정보입니다.

## 화면 흐름

1. Backtester에서 전략이나 전략 인스턴스를 포함한 포트폴리오를 저장합니다.
2. Live Trader의 **운용 전략 → Backtester 전략 연결**에서 저장본과 연결 계좌를 고릅니다. **가용 현금 사용 비율**은 해당 계좌에서 이번 운용에 배정할 비율입니다.
3. **전략 연결 (주문 없음)**을 누르면 원본 해시, 모든 실행 단위, 계좌 식별 정보와 비율만 저장합니다. 잔고 조회, 계좌 설정 변경 또는 주문 전송은 하지 않습니다. 연결은 `backtested` / `MONITOR` 상태로 남으며 Paper 통과로 기록되지 않습니다.
4. 해당 배포를 선택하여 자료·계좌 준비 및 시작 점검을 진행합니다. 필요한 과거 데이터, 현재 계좌·거래 규칙, 원본 변경 여부와 주문 보호를 별도로 검사합니다.
5. 점검 결과를 확인한 사용자가 실제 시작을 누릅니다. 프로그램 등록이나 빌드만으로 거래를 시작하지 않습니다.

같은 전략을 서로 다른 계좌나 비율로 연결하면 별도 배포가 됩니다. 선택과 준비는 전략 이름뿐 아니라 정확한 배포 ID에 묶입니다. 현재 한 포트폴리오의 일반 운용 준비는 한 거래소·계좌 단위입니다. 거래소가 다른 전략은 각각 연결한 뒤 기존 다중 실행 기능으로 함께 운용할 수 있습니다. 혼합 거래소 포트폴리오를 자동으로 쪼개거나 임의 계좌에 배정하지 않습니다.

## 계속 확인하는 조건

- 저장본의 canonical 해시, 인스턴스 원본·파라미터·방향·실행 모델, 지원 플러그인과 거래 경로가 일치해야 합니다.
- 실제 데이터 기반 전략만 Live에 연결합니다. 샘플·합성·오프라인 전용 또는 데이터 출처 미상 전략은 Paper에서만 사용할 수 있습니다.
- 연결한 계좌 식별 정보·인증 설정·원본이 바뀌면 기존 준비 결과를 재사용하지 않습니다.
- 현재 잔고, 주문 크기와 거래소 규칙, 시간·시세 신선도, 주문 소유권, 중복 주문 방지, 손실·노출 한도와 긴급 정지는 유지합니다.
- 등록이 가능하다는 것은 수익성이 좋다거나 실거래가 검증되었다는 뜻이 아닙니다. 연구 결과는 원본에 그대로 남습니다.

## 현재 기술 범위

KIS 국내 공개 tick 초기화는 Paper 승급 정책 대신 직접 연결한 정확한 소스·포트폴리오 계약을 사용합니다. 현재 검증된 direct 경로는 5분봉, 서로 다른 국내 종목 1~32개, 전략별 1~50개의 준비 봉입니다. 필요한 준비 시간은 최대 lookback × 5분으로 계산합니다. sealed historical-source 계약, 거래일·세션, 실제 공개 tick/receipt 시각, 동일 수집 소유자, 독립 원문 재생과 REST 비교 근거는 계속 필요합니다. 이 기술 계약이 없는 소스를 고정 삼성전자·SK하이닉스·ETF의 과거 성공 기록으로 대체하지 않습니다. 단일 소스 KIS 일반 운용도 실행 인스턴스가 고정된 포트폴리오를 먼저 만들어야 합니다.

Binance 선물은 레버리지·마진·보호 손절 및 실제 주문 경로의 기존 검사에 따릅니다. 유효하지 않은 선물 실행 정책 또는 미구현 다중 선물 경로는 Paper 조건을 없앴다는 이유로 통과시키지 않습니다. 기존 주문 연결 시험과 일반 운용은 각자의 실행 경로를 유지합니다.

토스는 저장본의 명시적 `toss` 경로와 종목 식별자, 토스용 수량·비용 계약, 설정한 운용 예산 및 실제 API 점검이 필요합니다. KIS 전략을 토스 계좌로 조용히 바꾸어 실행하지 않습니다. 이번 변경은 API 연결 성공이나 실제 체결을 새로 검증하지 않았습니다.

## 검증 범위

오프라인 합성 회귀에서 실제 canonical artifact/instance/portfolio loader, 직접 등록, 일반 운용의 배포 binding과 주문 manifest, source/account 변경 차단을 확인합니다. KIS는 실제 공개 데이터 파서·초기화 수집기·독립 raw 재생을 합성 프레임으로 검증합니다. 실제 앱 시작, 개인 계좌 조회, 유료 AI, 주문·취소 또는 실제 장중 세션을 실행한 검증과 구분합니다.
