# 설명·오류 문장 영역 투명화 (2026-09-09)

회색 안내 상자가 남던 계좌 연결 오류, 긴급 정지 피드백, 기능시험 안내·실패·빈 상태, 코인 시험 경고와 검증 오류에 `ts-text-region`을 명시했다. 공유 규칙(c3f2f1b)은 이 영역의 배경·테두리·그림자만 제거하며 본문·로그·상태 배지·버튼 의미색과 간격은 유지한다. 전역 문장 선택자나 임의 카드 투명화는 사용하지 않는다.

프로덕션 빌드와 workflow 82개, 공식 패키징의 100/125/150% 배율 계약이 통과했다. 오프라인 합성 자료로 1024/1920 × 화이트/다크에서 88개 화면 상태·7,166개 텍스트를 확인했다. 실제 문장 영역 24회와 정적 설명 12회에서 배경 투명·테두리 0px·그림자 없음, 희귀 오류 클래스 10종의 60개 테마 조건도 통과했다. 선택 버튼 204회·주요 버튼 44회·위험 버튼 108회, 별도 두 강조색 검사와 로그 의미색 8개 화면도 정상이다. 테마 저장·재시작 복원·레이아웃 초기화와 계좌 필터/정렬/시세 누락 표시를 함께 확인했다. 실제 주문·수집은 실행하지 않았다.

공식 build_exe.ps1 -PendingOnly -SkipDependencyInstall이 성공했다. 패키지 내 프런트엔드 파일 6개는 dist와 바이트가 같으며 기존 EXE를 백업하고 release/LiveTrader.exe를 교체했다. 기존 CryptoFirstLivePanel 미커밋 변경은 새 클래스만 제거한 본문이 작업 전과 같음을 확인했고, 커밋은 HEAD에 이번 클래스만 합성한 내용으로 제한했다. 다른 진행 중 변경은 보존했다.
