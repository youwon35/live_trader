# 통합증거금 계좌의 국내·해외 자금 준비

Live Trader의 KIS 해외 결제 방식 기본값은 `INTEGRATED_MARGIN`이다. 원화로 해외 주문을 지원하는 계좌 선호이며, 이 선택만으로 주문 권한이나 실거래 자격을 발급하지 않는다.

## 이번에 연결한 조회

읽기 전용 준비 화면에서 국내 또는 미국 종목을 선택하고 계좌 조회를 요청하면 공식 `TTTC0869R` 통합증거금 현황을 한 번 조회한다. 이 API의 `WCRC_FRCR_DVSN_CD=02`, `FWEX_CTRT_FRCR_DVSN_CD=02`는 **원화 기준 표시**를 뜻한다. 다른 잔고 API의 동명 구분 코드와 혼용하지 않는다. 국내 한도, 해외 사용액, 통화별 주문가능액, 기준 환율을 각각 관측하고 더하거나 달러 현금으로 바꾸지 않는다.

같은 계좌의 기존 프로그램 원금과 영수증도 고정 로컬 경로에서 읽기 전용으로 확인한다. DB가 없거나 변경 중이면 미확인으로 남긴다. 새 DB·원금·예약은 만들지 않는다. KRW와 USD 원장을 분리해서 진단하며, 과거 설정 원장을 현재 설정으로 덮어쓰지 않는다.

준비 화면에는 항목 수·필드 상태·대조 차단 이유만 전달한다. 계좌번호·API 키·원격 문구·개별 잔액·로컬 원장 금액은 진단 응답에 포함하지 않는다. 실제 체결·미체결 전체 범위, 계좌 적용 수수료, 자동환전, 확정 정산을 증명하지 못하므로 공통 원화 예약 검증과 해외 자동 주문은 계속 차단한다.

## 실제 계좌에서 확인된 범위 (2026-10-19)

주문 없이 OAuth 1회와 계좌 GET 4회를 수행했다. 통합증거금 현황의 수치 항목 34개는 모두 형식상 유효했다. 값이 존재한다는 의미이며 양수 자금이나 계좌 전체 조회 완료를 뜻하지 않는다.

외화상세에는 USD 행이 여러 개 있었지만 임의 합산하지 않았다. 현재 잔고와 직전 완료 영업일인 2026-10-16 결제기준 잔고에서는 명시적인 USD 현금 행을 확인하지 못했다. **빈 응답은 달러 잔고 0원, 거래 불가, 자금 부족의 증거가 아니다.** 조회 결과는 계좌별 수수료나 실제 자동환전·정산 완료의 증명도 아니다.

## 사용자가 확인할 정보

한국투자앱 **고객지원 → 고객센터 → 수수료 안내**, 또는 HTS **[7912]**에서 본인 계좌에 적용되는 다음 조건을 확인한다. 일반 수수료표만 보이면 해외주식 상담 **02-3276-5300**에 “통합증거금 계좌의 OpenAPI 적용 요율과 자동환전 우대”를 문의한다.

- 미국 주식·ETF의 매수/매도 수수료율, 최소수수료, 우대 종료일, OpenAPI 적용 여부
- 통합증거금 자동환전의 적용 환율·우대율 또는 스프레드, 적용 시점

기존 거래가 있다면 앱에서 **해외주식 거래내역**, **환전내역**, **통합증거금**을 검색해 거래일·결제일·실제 수수료/제비용, 자동환전일·원화/외화 금액·적용환율·확정 상태를 확인한다. 정확한 과거 거래일을 모르는 상태이며 전체 거래 이력이 없다고 단정하지 않는다. 검증용 신규 매매·입금·환전은 필요 없다. 자료 공유 시 계좌번호·개인 식별정보는 가린다.

통합증거금은 원화와 다른 시장의 결제 예정 자금을 해외 주문의 증거금으로 활용하고 증권사 일정에 따라 환전·정산할 수 있다. 화면의 주문가능액, 보유 달러, 확정 결제 현금은 역할이 다르다. 과거 거래내역의 등록 환율도 실제 자동환전 체결 환율과 동일하다고 가정하지 않는다.

## 남은 구현·검증

현재 통화별 프로그램 원장은 공통 원화 한도의 원자적 예약을 대신하지 않는다. 계좌 전체 주문·현금 범위와 실제 비용·환전·정산 계약이 확인된 뒤에야 국내·해외가 같은 원화를 중복 배정하지 않는 예약 생산자와 최종 반영 검증을 완성할 수 있다. 이 문서와 준비 진단은 해당 검증을 통과했다는 증명이 아니다.
